# fdbx tutorials

Plain-language guides to each fdbx method: what it does, when to reach for it, what it produces, and the insight that makes it work. Read one before running the skill, or share it with a team that hasn't used the method before.

| Method | Use it when… |
|---|---|
| [Causal Layered Analysis](causal-layered-analysis.md) | the brief feels obvious, or the team keeps designing the same thing |
| [Futures Triangle](futures-triangle.md) | you need to see what is pulling, pushing and weighing on the future of an issue |
| [Four Futures](four-futures.md) | the roadmap has one future in it, usually growth |
| [Three Horizons](three-horizons.md) | you need a transition from today's model to the next, and to know which innovations matter |

## Suggested order

1. **Deepen** with Causal Layered Analysis, so you are working on the right problem.
2. **Map** with the Futures Triangle, so you know the forces at play.
3. **Experience** alternatives with Four Futures, so you don't design for a single default future.
4. **Plan** the transition with Three Horizons.

Each method also stands alone. Every tutorial ends with its sources, and each skill's `references/provenance.md` gives the page for every claim.
